# PACKFLOW — 수정본

## 열기

PACKFLOW.html은 더블클릭해서 실행할 수 있습니다. 소스 버전은 `python3 server.py`로 실행한 뒤 http://localhost:8765 에서 확인합니다.

## 이번 수정

- PACKFLOW 이름, 검정·그레이·화이트 UI. 기존 소개 문구, 프로젝트 예시 이름, 장식 아이콘과 XYZ 축 삭제
- 3D 렌더링 영역 1920:1080(16:9), 동일한 가로 폭의 짧은 전개도 영역
- 구조 / 디자인 / 완성 탭 전환
- 구조: 기성 전개도, SVG/DXF 업로드, 치수 입력
- 디자인: 재질, 이미지 업로드, 종이 색상, 후가공. 3D/2D 면 선택 표시, 이 면 비우기 / 전부 비우기
- 재단 빨강 / 오시 파랑 / 블리드 자홍 / 안전영역 초록. 선 스타일 구분과 개별 숨김
- 박스에 기본으로 들어가던 모든 예시 디자인·문구 제거
- 완성: 검수 항목, 확인 위치 표시, 개념·이유·수정법, 사용자 확인 체크, GPT 연결 상태, 촬영 설정 및 내보내기

## 검수 연결 상태

GPT 실연결은 아직 완료하지 않았습니다. 사용자 GPT의 지침·모델·서버 키가 제공되지 않았습니다. 로컬 검수 안내는 정적으로 작성한 실무 가이드이며 GPT의 자동 판정이 아닙니다.

`server.py`에 서버 측 Responses API 연결 코드를 포함했습니다. 서버 환경에 OPENAI_API_KEY, PACKFLOW_REVIEW_MODEL, PACKFLOW_REVIEW_INSTRUCTIONS(검수 지침 파일 경로)를 설정한 뒤 서버를 실행하세요. 웹사이트의 완성 → GPT 검수 → 연결 설정에는 `http://localhost:8765/api/review`를 입력합니다. API 키는 웹페이지·프로젝트·채팅에 입력하지 않습니다.

OpenAI API 구현은 [공식 Responses API 가이드](https://developers.openai.com/api/docs/guides/migrate-to-responses)를 참고했습니다. 서버는 사용자 지침을 instructions에, 패키지 정보와 미리보기 이미지를 input에 전달합니다. 실제 모델 호출 및 응답 품질 검증은 연결 정보가 없어 수행하지 않았습니다.

다른 검수 서버를 연결할 때는 JSON POST 요청을 받아 `{ "review": "검수 결과" }` 형태로 응답해야 합니다. 요청에는 패키지 치수/재질/후가공, 선택 면, 수동 검수 체크, 전개도 SVG, 3D PNG 미리보기, 디자인 배치 정보가 포함됩니다. 서버가 CORS와 인증을 구현해야 합니다. 제공된 로컬 서버는 같은 localhost 웹페이지에서 보내는 요청만 허용합니다.

## 남은 기능 범위

0201 택배박스, 0203 완전겹침, 슬리브의 2D/3D 연결과 치수 조정은 동작합니다. 나머지 기성 5종 및 사용자 업로드는 2D 검토용이며 자동 3D 조립과 디자인 면 매핑은 지원하지 않습니다. DXF 업로드는 LINE, 직선 LWPOLYLINE, TEXT를 지원하고 곡선/블록 등 미지원 객체는 오류로 안내합니다. 사용자 SVG에서는 스크립트·외부 이미지 등 비구조 요소를 제거합니다. 구조선 레이어 ID가 없는 SVG는 개별 선 종류를 자동 추정하지 않습니다.

재질/무광/유광/소프트터치는 시각적 근사 표현입니다. 부분 UV·박·형압은 미구현입니다. 블리드는 전체 경계 참고선으로, 칼선을 정밀 오프셋한 생산용 데이터가 아닙니다. 접착 날개와 열실링 영역은 구분해서 안내합니다.

## 검증

JavaScript/Python 구문 검사, 3종의 5개 접힘 상태에서 축 연결 유지 검사, 8종 DXF 파싱, TIFF/PNG 메타데이터 검사를 통과했습니다. Chrome에서 무채색 화면, 예시 없는 3D 박스, 구조/디자인/완성 탭 전환, 검수 안내 표시를 확인했습니다. 서버 미설정 시 503, 허용되지 않은 출처는 403으로 응답함을 확인했습니다. 실제 GPT 호출은 미검증입니다.
